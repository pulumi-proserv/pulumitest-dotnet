# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Email
[security@pulumi.com](mailto:security@pulumi.com) with a description of the
issue, steps to reproduce, and the affected version. You will receive an
acknowledgement within two business days.

## Scope

This library drives the Pulumi CLI through the Automation API against real
cloud accounts. Reports about credential handling, temp directory contents, or
stack destruction behaviour are especially welcome.

## Supported versions

Only the latest released version receives security fixes.
